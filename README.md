# 바로일본어

일본 워크샵/여행 현장에서 쓰는 선택형 통역·여행 문장 앱 MVP입니다.

## 실행 방법

이 폴더에서 간단한 정적 서버를 실행합니다.

```powershell
py -m http.server 5177
```

브라우저에서 접속:

```text
http://localhost:5177
```

## 파일 구성

- `index.html` — 앱 진입점
- `styles.css` — 모바일 UI 스타일
- `phrases.js` — 장소/상황/단어/문장 데이터
- `app.js` — 화면 전환, 문장 생성, 즐겨찾기/최근 사용 로직
- `PLAN.md` — 기획안

## 현재 MVP 기능

- 장소 선택: 음식점, 술집/이자카야, 편의점/가게, 택시/이동, 숙소 정보, 비상 표현
- 상황별 문장 템플릿 선택
- 단어/수량/요청 버튼 선택
- 한국어 / 일본어 / 발음 표시
- 직원에게 보여주는 큰 글씨 모드
- 복사 기능
- 일본어 음성 읽기 기능: 브라우저 지원 시 사용 가능
- 즐겨찾기 / 최근 사용 저장: 브라우저 localStorage 사용
- 숙소 고정 정보: 호텔명, 주소, 택시용 문구, 길 묻기

## 검증 예시

- 술집/이자카야 → 술 주문 → 맥주 + 2잔
- 결과: `ビールを2杯ください。`
